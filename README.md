# CyberGuard – Güvenlik Log Analiz Sistemi

CyberGuard, basit bir güvenlik log analiz sistemidir. Kullanıcı giriş denemelerini SQLite veritabanında saklar ve Python ile analiz eder.

## 🚀 Özellikler
- SQLite veritabanında log saklama
- Pandas ile log analizi
- Şüpheli IP adreslerini tespit etme

git clone https://github.com/EsmaNur/CyberGuard.git
